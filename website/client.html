BEFORE YOU DROP IN

A few things
to know.

Need a hand? Open an issue
Launcher or standalone: which do I need?

For the full desktop experience, install the Windows EXE and create a compatible Fabric instance. Already have a launcher? Put the standalone JAR in your Minecraft 1.21.11 mods folder with Fabric Loader 0.18.1 or newer and Java 21. Replace any older Eternal Core JAR.

How do I open the in-game interface?

The Eternal title menu appears at startup. Press Right Shift in game for the module library, then use HUD to open the editor. Press H for the HUD editor shortcut. Modules start disabled on a clean install; enable the ones you want.

Do the combat presets play for me?

No. They configure informational HUD modules and your crosshair. Attack cooldown, durability, movement and supply readouts show your local game state. They do not automate attacks or movement.

How do resource packs, datapacks and shaders install?

Resource packs go into your instance’s resourcepacks folder; enable them in Minecraft. Datapacks go into the selected world’s datapacks folder; reopen the world to load them. Shaders go into shaderpacks and need a compatible shader loader, such as Iris, plus selection in its settings. Close the instance before changing content.

How do I install on Linux Mint XFCE?

Download the amd64 DEB from the v1.2.1 release. In its download folder, run sudo apt install ./Eternal.Client.1.2.1.linux-amd64.deb, then open Eternal Client from the Games menu. Select Java 21 in Settings for Fabric 1.21.11. Read the Linux guide. CI checks install and launch under Xfce on Ubuntu 22.04 and 24.04; live gameplay and a physical Mint desktop remain untested.

Does FPS Optimizer guarantee more FPS?

No fixed gain is promised. It changes supported native Minecraft graphics options, so results depend on your system and scene. Disabling it restores the values captured when it was enabled.

Can I create an Aternos server here?

Eternal opens the official Aternos dashboard, where you create and manage your server. Save the address in Eternal to ping or join it. In-client creation, start/stop and console controls are not available. Eternal is not partnered with Aternos.
