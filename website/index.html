05FAQ

Before you launch.

The important stuff, without the wall of text.

Is Eternal Client free?+

Yes. The current Eternal Client and Eternal Core release can be downloaded directly from the public GitHub release page.

Can I use Eternal Core without the launcher?+

Yes. Download the standalone Core JAR and place it in a compatible Fabric 1.21.11 mods folder running Java 21.

Does Eternal support Forge / NeoForge / Quilt?+

The launcher currently advertises only launch paths that are implemented: Vanilla and Fabric. Eternal Core itself targets Fabric 1.21.11.

Does the launcher fake progress or module state?+

No. Eternal's release is built around real local profile, runtime, transfer, Core config and Minecraft state. Unknown-size work stays indeterminate instead of inventing a percentage.

What happens if the in-game UI fails?+

Eternal Core keeps a guarded safe-mode path and writes diagnostic information to its local Core log instead of intentionally crashing Minecraft.
