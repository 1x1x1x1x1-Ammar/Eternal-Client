Questions.

Is Eternal Client free?+

Yes. The current Eternal Client release and standalone Core are available from the project's public GitHub release.

Does the launcher include Eternal Core?+

Yes. The full launcher stages the verified Core build and exposes the Customization Studio for its settings.

Can I use Eternal Core without the launcher?+

Yes. Use the standalone JAR on a compatible Fabric 1.21.11 installation with Java 21.
