Questions,
answered.

Is Eternal free?+

Yes. The public v1.1.0 Windows installer and standalone Eternal Core JAR are distributed through the project’s GitHub Releases page.

What is the difference between Eternal Client and Eternal Core?+

Eternal Client is the complete desktop launcher experience. Eternal Core is the standalone Fabric mod containing the in-game Eternal Start, ClickGUI 2.0, HUD Studio and implemented client utilities.

What Minecraft version is this release for?+

The current standalone Core targets Minecraft Java Edition 1.21.11 with Fabric and Java 21.

How do I verify a download?+

Every stable release publishes SHA-256 checksums. Compare the file hash against SHA256SUMS.txt from the same GitHub release.
